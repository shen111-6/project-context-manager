# Decision: 决策标题

- ID: 沿用项目标识规则（如存在）
- Status: Proposed / Accepted / Superseded（选择实际状态）
- Date: 决策发生时间；未知则明示，不用文档生成日期冒充
- Scope: 决策适用的项目/模块

## Decision

具体结论及边界。

## Reason

有来源的需求、约束、比较与理由；仅记录仍影响未来工作的内容。未知理由明确说明，不补造历史讨论。

## Impact

对接口、开发、运维、兼容性及未来工作的实际影响与取舍。

## Evidence / Acceptance

批准或达成决策的可访问依据；相关代码仅说明实现状态，不能单独证明决定已被接受。

## Implementation Status

引用当前实现证据、尚未落实的部分或偏差；状态分类采用共享规则。

## Reconsider When

足以重新评估该决策的新证据、需求变化或失效条件。

## Supersedes / Superseded By

已被明确替代时填写前后记录链接；否则写不适用。保留原决策及理由。
