# Codex Work Checkpoint

> WIP 事实快照，不是最终事实来源或完成报告。复用现有格式时保留下列语义；未知/不适用如实说明。

## Current Goal
当前目标和范围。

## Current Task
当前任务及实际实现状态。

## Progress Since Last Checkpoint
旧断点引用与本次确认的变化；首次保存时注明。

## Work In Progress
部分实现、正在修改、剩余接线/验收缺口；不得将半成品列作完成。

## Relevant Files / Symbols
相关文件、符号和实际已查证据。

## Branch / HEAD / Working Tree
写入前分支、HEAD；区分暂存、未暂存、相关未跟踪、冲突及相关改动。

## Validation
命令/目录、实际状态、时间/基线、范围、失败摘要或未运行原因。

## Current Blockers
当前阻碍及影响。

## Important Constraints
有效决策/约束、理由摘要与出处。

## Next Exact Action
目标文件/符号、动作、验收方式和前置条件。

## Evidence Scope / Verification Baseline
Repository / Project Scope、Subproject、Relevant Files Inspected；Branch / HEAD / Working Tree 和 Validation Run 引用上文，按共享规则保留完整基线语义。

## Evidence Gaps
未检查范围、缺失来源、未验证事项和冲突。

## Last Verified
实际核验时间和明确时区，不以生成时间冒充核验时间。
