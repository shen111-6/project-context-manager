# 可复查的离线演示

从项目根目录执行：

```sh
npm ci --ignore-scripts
npm run demo
```

需要 Node.js >=22.12 和 Git。使用已安装本地依赖，命令先构建核心，再在 Git 忽略的 `outputs/demo/run-*` 创建独立合成项目。不调用 Agent、不需要登录，也不把演示数据发到外部。

实际执行七个场景：缺少记录时失败；保存 checkpoint；继承任务生成 handoff；恢复目标/WIP/下一步并比较五项文件/index 哈希；修改合成源码识别 FILE_DRIFT；只篡改合成快照并拒绝恢复；预先取消请求返回 cancelled。脚本用断言核对结果，不将期望失败视为演示失败。

成功时保留 `summary.json`、`report.md`、各阶段原始 JSON 和合成项目；失败时保留 `failure.json` 并以非零状态退出。不同运行使用不同目录，不覆盖实际项目交接记录。合成项目里执行 Git 初始化与提交，仅用于构造可验证基线。

报告中的毫秒数是这次单次操作耗时；不是多样本性能基准，不能推导效率提升。预先取消场景只证明已取消请求不执行操作，不代表运行中 GUI 取消通过。需要 AI 分析时，另行使用明确授权的 Codex 入口；这条离线演示没有测试模型推理。
