# M5 local reliability increment

Implemented bounded collection with explicit scope exclusions, portable safe paths, non-Git evidence inspection, separate authorized validation execution and real simultaneous publication tests. Read-only operations never invoke validation. Validation runs record actual exit results and recheck their input baseline; a successful exit with changed inputs is Incomplete. Processes receive a minimal environment, not inherited provider tokens. A custom process remains user-selected code and can have side effects: it is not a sandbox.

CLI and GUI share post-publication checks. Once an index has committed a record, follow-up failures retain the real artifacts and report partial state; no retry silently overwrites that record. Immutable snapshot contents remain distinct from later diagnostics. GUI advanced operations expose file evidence and safe Git diffs.
